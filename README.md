This is a simple project to refresh my knowledge of Python, namely Object Oriented Programming and Sqlite. Both of which I have previously used


This is a simple CLI todo list app that allows the user to add tasks to do and assign them a priority alongside mark them as completed.
It uses one table to store all tasks where the primary key of the tasks is an integer that auto increments when a new one is added.
The second field the task itself which is stored as a string. The third field is a the priority of the task which is either high medium
or low. The forth field is the date that is which is built into Sqlite. The last field is an integer that represents that whether a task 
has been completed or not (represented as a 1 or a 0).
